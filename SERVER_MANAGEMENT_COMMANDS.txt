2. HOW TO STOP, START, AND RESTART THE TRADING BOT
================================================================================
Run these commands INSIDE your server SSH terminal:

To CHECK if bot is currently running:
   sudo systemctl status nifty_terminal

To STOP the trading bot:
   sudo systemctl stop nifty_terminal

To START the trading bot:
   sudo systemctl start nifty_terminal

To RESTART the trading bot (Use after changing .env or settings):
   sudo systemctl restart nifty_terminal

To RESTART the Nginx Web Server (HTTPS / SSL):
   sudo systemctl restart nginx

To REBOOT the entire Linux cloud computer:
   sudo reboot

6. HOW TO VIEW LIVE REAL-TIME LOGS & DEBUG ERRORS
================================================================================
Run these commands INSIDE your server SSH terminal:

1. STREAM LIVE BOT LOGS (Watch every tick, candle, and user query as it happens):
   sudo journalctl -u nifty_terminal -f
   (Press Ctrl + C to exit the live stream)

2. VIEW LAST 100 LINES OF BOT LOGS:
   sudo journalctl -u nifty_terminal -n 100 --no-pager

3. VIEW THE ERROR LOG FILE:
   sudo tail -n 50 /var/www/nifty_terminal/logs/service_error.log

4. VIEW NGINX WEB ACCESS LOG (See live HTTPS visits):
   sudo tail -n 50 /var/log/nginx/access.log

5. VIEW NGINX WEB ERROR LOG:
   sudo tail -n 50 /var/log/nginx/error.log

1. View the 10 most recent registered users:

5. View user drawings count:
   sqlite3 /var/www/nifty_terminal/database/users.db "SELECT user_id, drawing_type, COUNT(*) FROM user_drawings GROUP BY user_id, drawing_type;"

9. EMERGENCY TROUBLESHOOTING & RESET COMMANDS
================================================================================
If anything ever goes wrong:

1. If the bot won't start after a bad code change, reset server files to GitHub:
   cd /var/www/nifty_terminal
   git reset --hard origin/main
   sudo systemctl restart nifty_terminal

2. If database ever gets locked by SQLite:
   sudo systemctl stop nifty_terminal
   sudo rm -f /var/www/nifty_terminal/database/users.db-wal /var/www/nifty_terminal/database/users.db-shm
   sudo systemctl start nifty_terminal

3. If Nginx web server gives 502 Bad Gateway:
   sudo systemctl restart nifty_terminal
   sudo systemctl restart nginx

4. If you edit .env credentials on the server:
   sudo nano /var/www/nifty_terminal/.env
   (Save: Ctrl + O, Enter. Exit: Ctrl + X)
   sudo systemctl restart nifty_terminal

5. Check automated SSL renewal status:
   sudo systemctl status certbot.timer
   sudo certbot renew --dry-run
